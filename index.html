다양한 기계식 키보드 축 간단 가이드 (12종)

기계식 키보드는 어떤 ‘축(스위치)’이 들어가느냐에 따라 소음과 손끝 느낌이 크게 달라집니다. 아래 12가지 대표 축을 참고해 내 취향과 환경에 맞는 축을 골라보세요.

저소음 적축 (Silent Red) 저소음 리니어

적축 내부에 소음 감쇠 댐퍼를 넣어 바닥·복귀 소음을 줄인 축. 걸림 없이 부드럽고 조용해 사무실·도서관용 정석으로 꼽힙니다.

피치축 / 저소음 피치축 저소음 리니어

오테뮤·AULA 등에서 많이 쓰이는 가벼운 저소음 리니어 계열. 폭신한 바닥감과 정숙한 소음 덕분에 가성비 저소음 키보드에서 인기가 높습니다.

바다소금축 / 저소음 바다소금축 리니어 · 저소음

하이무 등에서 선보인 특주 축. 일반 바다소금축은 경쾌한 ‘도각’ 타건음이 특징이고, 저소음 바다소금축은 댐퍼를 넣어 매우 조용하게 다듬은 버전입니다.

라임축 / 저소음 라임축 저소음 택타일

피치축처럼 소음은 억제하면서도, 눌릴 때 갈축처럼 가벼운 걸림감(구분감)이 느껴져 심심하지 않은 타건감을 주는 저소음 축입니다.

적축 (Red) 리니어

중간 걸림 없이 위에서 아래로 쑥 내려가는 기본 리니어 축. 가볍고 손가락 피로가 적어 게임과 장시간 타이핑 모두에 무난합니다.

황축 (Yellow) 리니어

적축보다 살짝 더 탄력 있고 쫀득한 반발력을 가진 리니어 축. 부드럽게 미끄러지면서도 적축보다 덜 가벼워 게이밍·타이핑 겸용으로 인기입니다.

흑축 (Black) 리니어 (고압)

적축처럼 걸림은 없지만 스프링 압력이 높아 묵직하게 눌리는 축. 오타가 적고 탄탄한 키감을 좋아하는 분에게 맞지만 손 힘이 더 필요합니다.

소금축 (Sea Salt / Ice Salt 등) 리니어

깔끔하고 정갈한 ‘조약돌/도각’ 계열 타건음으로 사랑받는 커스텀 리니어 축. 맑고 단정한 소리를 원할 때 많이 선택합니다.

치즈축 (Cheese / Cream Cheese) 리니어

크리미하고 부드러운 키감과 낮고 둥근 ‘보글·도각’ 톤의 타건음을 내는 커스텀 리니어 계열 축(제조사별 세부 압력·소리 성향 상이).

갈축 (Brown) 택타일 (걸림)

눌리는 중간에 살짝 ‘걸리는’ 구분감이 있으면서 청축보다 조용한 만능 밸런스 축. 기계식 특유의 손맛과 무난한 소음 사이에서 많이 고릅니다.

청축 (Blue) 클릭 (찰칵)

‘찰칵’ 하는 경쾌한 클릭음과 확실한 구분감이 매력인 대표 축. 타건 재미는 크지만 소음이 매우 커서 사무실·공공장소에는 적합하지 않습니다.

백축 (White / Clear) 클릭 / 넌클릭

브랜드에 따라 성격이 나뉩니다. 카일 박스 백축은 청축보다 더 또렷한 클릭음, 체리 백축(클리어)은 갈축보다 묵직한 걸림감을 줍니다.
